# 让 Minis 自动复制另一台设备的所有 Skills

**Let Minis Auto-Copy All Skills from Another Device**

> 💬 *From the Open Minis community — shared by **如幻** on 2026-03-22*

---

## 🎯 痛点 / Pain Point

**中文：** 在多个 AI Agent 平台间迁移技能配置需要手动逐一重建，耗时费力。

**English:** Migrating skill configs between AI agent platforms requires manual rebuilding one by one.

---

## 💡 做了什么 / What It Does

**中文：** 让 Minis 自动识别并复制另一个 AI Agent（如 OpenClaw）上的所有技能/工具配置，快速完成跨平台 skill 迁移，无需手动逐一设置。

**English:** Ask Minis to automatically detect and copy all skills/tool configs from another AI agent (e.g. OpenClaw). Instant cross-platform skill migration — no manual setup.
