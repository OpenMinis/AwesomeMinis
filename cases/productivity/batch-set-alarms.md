# Batch Set Complex Alarm Schedules

> 💬 *From appinn.com · 2026-03-28*

---

## 🎯 Pain Point

Setting multiple alarms with different times and repeat rules (weekday schedules, specific dates) one by one is slow and error-prone.

---

## 💡 What It Does

Describe your alarm requirements to Minis, and it creates all alarms in one batch — including complex repeat rules — without any manual tapping.

---

## 🛠 Skills Used

| Skill | Purpose |
|-------|---------|
| Built-in `apple-alarm` | Create alarms in a batch |

---

## 💬 Example Prompt


```
Set the following alarms for me:
- Mon–Fri 6:30 AM, label "Wake up"
- Mon–Fri 7:00 AM, label "Leave home"
- Sat–Sun 8:30 AM, label "Weekend wake up"
- Daily 10:30 PM, label "Get ready for bed"
```
